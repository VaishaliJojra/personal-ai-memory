# Security Policy

## Supported Versions

This project is currently maintained as a personal portfolio project.

Only the latest version on the `main` branch is actively maintained.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately through GitHub rather than creating a public issue.

You can use GitHub's private vulnerability reporting or security advisory features when available.

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any relevant logs or screenshots

Please do not publicly disclose a security vulnerability before it has been reviewed and addressed.

## Secrets and API Keys

Never commit API keys, passwords, tokens, credentials, `.env` files, or other sensitive information to this repository.

The project uses `.gitignore` to exclude local environment files and data from Git.
